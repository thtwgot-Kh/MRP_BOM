ยังไม่เชื่อมต่อ
Apps Script ที่เชื่อมอยู่ยังเป็นโค้ดเวอร์ชันเก่า — กรอกและคำนวณได้ตามปกติ แต่ กดบันทึกจะไม่สำเร็จ (โค้ดเก่ารับได้ทีละ 1 Item จึงตอบกลับว่า missing order.item)
วิธีแก้: เปิดชีท → ส่วนขยาย → Apps Script → วางโค้ด apps-script/Code.gs ล่าสุด → บันทึก → รัน initializeSheet หนึ่งครั้ง → Deploy → Manage deployments → ไอคอนดินสอ → Version: New version → Deploy

1. ข้อมูลคำสั่งผลิต

จำนวนที่สั่งย้ายไปกรอกรายตัวสินค้าในหัวข้อ 3 แล้ว (หนึ่งคำสั่งผลิตสั่งได้หลาย Item)

2. กำหนดเริ่ม–เสร็จของแต่ละแผนก

ระบุวันเริ่มและวันเสร็จของแต่ละแผนกในสายการผลิต — แผนกที่ไม่เกี่ยวข้องกับคำสั่งผลิตนี้เว้นว่างไว้ได้

แผนก กำหนดเริ่ม กำหนดเสร็จ

3. รหัสสินค้า (ITEM)

หนึ่งบรรทัด = หนึ่ง Item — เลือก รุ่นสินค้า + Packaging + เฉดสี แล้วใส่จำนวนที่สั่งต่อท้าย กด "+ เพิ่ม Item" เพื่อต่อบรรทัดลงมาเรื่อย ๆ เมื่อครบทุก Item แล้วค่อยกดปุ่มโหลดสูตรด้านล่างครั้งเดียว

รุ่นสินค้า (Base Model) Packaging เฉดสี (Color Set) จำนวนที่สั่ง

4. รายการวัตถุดิบแต่ละ Item

แก้ไข/เพิ่ม/ลบได้อิสระ — กดหัวข้อของ Item เพื่อย่อ/ขยายตาราง

ยังไม่มีรายการวัตถุดิบ — เลือก Item ด้านบนแล้วกด "โหลดสูตรวัตถุดิบทุก Item"

5. สรุปวัตถุดิบรวมทั้งคำสั่งผลิต

รวมความต้องการวัตถุดิบของทุก Item เข้าด้วยกัน (วัตถุดิบรหัสเดียวกันที่ใช้หลาย Item จะถูกบวกรวม)

รหัสวัตถุดิบ ชื่อวัตถุดิบ หน่วย ใช้ใน Item รวมต้องใช้ รวมคงคลัง รวมต้องเบิก/สั่งซื้อ

ยังไม่มีรายการวัตถุดิบให้สรุป
