ยังไม่เชื่อมต่อ

1. ข้อมูลคำสั่งผลิต

จำนวนที่สั่งย้ายไปกรอกรายตัวสินค้าในหัวข้อ 3 แล้ว (หนึ่งคำสั่งผลิตสั่งได้หลาย Item)

2. กำหนดเริ่ม–เสร็จของแต่ละแผนก

ระบุวันเริ่มและวันเสร็จของแต่ละแผนกในสายการผลิต — แผนกที่ไม่เกี่ยวข้องกับคำสั่งผลิตนี้เว้นว่างไว้ได้

แผนก กำหนดเริ่ม กำหนดเสร็จ

3. รหัสสินค้า (ITEM)

ประกอบรหัสจาก รุ่นสินค้า + Packaging + เฉดสี แล้วใส่จำนวนที่สั่งต่อท้าย — กด "+ เพิ่ม Item" เพื่อสั่งผลิตหลายตัวในคำสั่งเดียว แล้วกด "โหลดสูตรวัตถุดิบทุก Item" ครั้งเดียวเพื่อดึงสูตรเดิมและคำนวณให้พร้อมกัน

4. สรุปวัตถุดิบรวมทั้งคำสั่งผลิต

รวมความต้องการวัตถุดิบของทุก Item เข้าด้วยกัน (วัตถุดิบรหัสเดียวกันที่ใช้หลาย Item จะถูกบวกรวม)

รหัสวัตถุดิบ ชื่อวัตถุดิบ หน่วย ใช้ใน Item รวมต้องใช้ รวมคงคลัง รวมต้องเบิก/สั่งซื้อ

ยังไม่มีรายการวัตถุดิบให้สรุป
