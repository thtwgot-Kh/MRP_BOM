# ระบบบันทึก BOM (BOM Data Entry)

เว็บแอปสำหรับกรอกข้อมูล BOM (Bill of Materials) แทนไฟล์ Excel เดิม ใช้งานง่ายกว่าเดิมด้วย:

- **ช่องค้นหาแบบ Combobox** (พิมพ์เพื่อค้นหา + เลือกจากรายการ + เพิ่มรายการใหม่ได้ทันที) สำหรับ รุ่นสินค้า, รหัส Packaging, เฉดสี และรหัสวัตถุดิบ
- **ตัวสร้างรหัส ITEM อัตโนมัติ** จากรูปแบบเดิม เช่น `First-GC-23/P(P)-Y` → รุ่นสินค้า + `(รหัส Packaging)` + `-เฉดสี`
- **โหลดสูตรวัตถุดิบจากระบบเดิมอัตโนมัติ** ถ้ารหัส ITEM เคยมีอยู่ในไฟล์ MRP เดิม (นำเข้าไว้แล้ว 1,799 รายการ จาก 884 สินค้า)
- **คำนวณจำนวนที่ต้องเบิก/สั่งซื้อ** อัตโนมัติจาก จำนวนสั่ง FG × จำนวนใช้ต่อ 1 FG − คงคลัง
- **ข้อมูลบันทึกลง Google Sheet ของคุณโดยตรง** ผ่าน Google Apps Script (ไม่ต้องมี Service Account หรือ credential ใด ๆ)
- **ประวัติการบันทึก** ค้นหาย้อนหลัง และ "ใช้เป็นแบบร่างใหม่" เพื่อคัดลอกรายการเดิมได้ทันที

โครงสร้างโปรเจกต์:

```
apps-script/   Google Apps Script backend (ผูกกับ Google Sheet)
  Code.gs        API หลัก (doGet/doPost) + ฟังก์ชันตั้งค่าเริ่มต้น
  SeedData.gs    ข้อมูลตั้งต้นที่นำเข้าจากไฟล์ MRP เดิม (สร้างอัตโนมัติ, ไม่ควรแก้มือ)
web/           เว็บแอป (static, ไม่ต้อง build) — index.html, app.js, styles.css
data/          ไฟล์ JSON ข้อมูลที่ดึงออกมาจากไฟล์ Excel เดิม (ไว้อ้างอิง/ตรวจสอบ)
scripts/       สคริปต์ที่ใช้แปลงข้อมูลจาก Excel → JSON → SeedData.gs
```

## ขั้นตอนที่ 1 — ตั้งค่า Google Apps Script (ทำครั้งเดียว)

1. เปิด Google Sheet ที่ต้องการใช้เก็บข้อมูล ([ลิงก์ชีทของคุณ](https://docs.google.com/spreadsheets/d/1CvMNe_mv8jUp1rjxRD85xOokNAcPJwKBK6kL46hDcRk/edit))
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ที่เปิดมา แล้ววางเนื้อหาทั้งหมดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ของโปรเจกต์นี้แทน
4. กดปุ่ม **+** ข้าง "Files" เพื่อเพิ่มไฟล์ Script ใหม่ ตั้งชื่อว่า `SeedData` แล้ววางเนื้อหาทั้งหมดจากไฟล์ [`apps-script/SeedData.gs`](apps-script/SeedData.gs) ของโปรเจกต์นี้ลงไป (ไฟล์นี้มีขนาดใหญ่ ~750KB เพราะเก็บข้อมูลวัตถุดิบเดิมทั้งหมด — เป็นเรื่องปกติ)
5. กด **บันทึก (Ctrl+S / Cmd+S)**
6. ที่แถบด้านบน เลือกฟังก์ชัน `initializeSheet` จากช่อง dropdown แล้วกด **Run** (▶)
   - ครั้งแรกจะมีหน้าต่างขอสิทธิ์ (Authorization required) → กด **Review permissions** → เลือกบัญชี Google ของคุณ → ถ้าเจอหน้าเตือน "Google hasn't verified this app" ให้กด **Advanced** → **Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow**
   - รอสักครู่ สคริปต์จะสร้างชีทย่อยทั้งหมด (BOM_Master, Materials_Catalog, FG_Base_Items, Packaging_Codes, Color_Shades, BOM_Orders, BOM_Order_Lines) และนำเข้าข้อมูลวัตถุดิบเดิมให้อัตโนมัติ
   - ถ้า Run สำเร็จจะเห็น log ว่า `OK`
7. Deploy เป็น Web App: เมนู **Deploy → New deployment**
   - Select type: **Web app**
   - Execute as: **Me (อีเมลของคุณ)**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

> เก็บลิงก์นี้ไว้ให้ดี ใครก็ตามที่มีลิงก์นี้จะสามารถบันทึกข้อมูลลงชีทได้ — อย่าเผยแพร่ลิงก์นี้แบบสาธารณะ

หากภายหลังแก้ไข `Code.gs` หรือ `SeedData.gs` ต้องทำ **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → Version: New version → Deploy** ใหม่ทุกครั้ง ลิงก์ URL จะเหมือนเดิม

## ขั้นตอนที่ 2 — เปิดใช้งานเว็บแอป

โฟลเดอร์ `web/` เป็นเว็บไซต์ static ธรรมดา (HTML/CSS/JS) ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์พิเศษ เลือกวิธีใดวิธีหนึ่ง:

- **GitHub Pages** (แนะนำ ฟรี): ใน repo settings → Pages → Deploy from branch → เลือก branch นี้และโฟลเดอร์ `/web`
- **เปิดจากเครื่อง**: ดับเบิลคลิกไฟล์ `web/index.html` ได้เลย (บางเบราว์เซอร์อาจบล็อก fetch จากไฟล์ local — ถ้าเจอปัญหาให้รันเซิร์ฟเวอร์เล็ก ๆ เช่น `npx http-server web`)
- **Netlify / Vercel**: ลาก-วางโฟลเดอร์ `web/` เพื่อ deploy ได้ทันที

เมื่อเปิดเว็บครั้งแรก ระบบจะพาไปหน้า **"การเชื่อมต่อ"** อัตโนมัติ:

1. วาง **Web app URL** จากขั้นตอนที่ 1 ข้อ 7
2. กด **บันทึกและเชื่อมต่อ**
3. สถานะมุมขวาบนจะเปลี่ยนเป็นจุดเขียว "เชื่อมต่อแล้ว"
4. (แนะนำ) กรอก **ชื่อผู้บันทึก** ไว้ด้วย เพื่อให้ทุกรายการที่บันทึกมีชื่อผู้กรอกกำกับ

ลิงก์และชื่อผู้บันทึกจะถูกจำไว้ในเบราว์เซอร์นั้น ๆ (localStorage) ไม่ต้องกรอกใหม่ทุกครั้ง

## วิธีใช้งาน

### สร้าง BOM ใหม่

1. **รหัสสินค้า (ITEM)** — พิมพ์ค้นหารุ่นสินค้าในช่องแรก ถ้าไม่มีในรายการ พิมพ์ชื่อใหม่แล้วเลือก "+ เพิ่มรุ่นสินค้าใหม่" ได้ทันที ทำแบบเดียวกันกับช่อง Packaging และเฉดสี
   - รหัส Packaging (P/B/X/C ในข้อมูลเดิม) จะถูกใส่ในวงเล็บ เช่น `(P)`
   - เฉดสี (A/Y/Z/B ในข้อมูลเดิม) จะยังไม่มีคำอธิบายในระบบ — **สามารถเพิ่มคำอธิบายภายหลังได้** โดยพิมพ์เพิ่มในช่อง "เฉดสี" ของเว็บ หรือเปิดชีท `Color_Shades` แล้วกรอกคอลัมน์ DESCRIPTION เพิ่มเองได้โดยตรง
   - ถ้าต้องการพิมพ์รหัส ITEM แบบเต็มเอง ให้ติ๊ก "แก้ไขรหัสเอง"
2. กด **"โหลดสูตรวัตถุดิบจากระบบเดิม"** — ถ้ารหัส ITEM นี้เคยมีสูตรอยู่แล้วในไฟล์ MRP เดิม ระบบจะดึงรายการวัตถุดิบทั้งหมดมาให้อัตโนมัติ (ไม่ต้องพิมพ์เอง)
3. กรอก **ข้อมูลคำสั่งผลิต** (ลูกค้า, จำนวนสั่ง FG, วันที่ ฯลฯ) — เมื่อกรอกจำนวนสั่ง FG ตัวเลข "ต้องเบิก/สั่งซื้อ" ในตารางจะคำนวณให้อัตโนมัติ
4. แก้ไข/เพิ่ม/ลบ **รายการวัตถุดิบ** ได้อิสระ — ค้นหารหัสวัตถุดิบจากคลังเดิม (1,016 รายการ) หรือเพิ่มรหัสใหม่ได้ทันที
5. กด **"บันทึกลง Google Sheet"**

### ประวัติการบันทึก

ดูรายการที่เคยบันทึกทั้งหมด ค้นหาด้วยรหัส ITEM/ลูกค้า และกด **"ใช้เป็นแบบร่างใหม่"** เพื่อคัดลอกรายการเดิมมาปรับแก้เป็นคำสั่งผลิตใหม่ได้ทันที

## โครงสร้างข้อมูลใน Google Sheet

| ชีท | เนื้อหา |
|---|---|
| `BOM_Master` | สูตรวัตถุดิบมาตรฐานเดิม (นำเข้าจากไฟล์ MRP, 1,799 แถว) ใช้เป็นฐานสำหรับ "โหลดสูตรจากระบบเดิม" |
| `Materials_Catalog` | รายชื่อวัตถุดิบทั้งหมดแบบไม่ซ้ำ (1,016 รายการ) ใช้เป็นตัวเลือกค้นหาในฟอร์ม |
| `FG_Base_Items` | รายชื่อรุ่นสินค้า (base model) ที่เคยใช้ |
| `Packaging_Codes` | รหัส Packaging (`P`,`B`,`X`,`C`) + คำอธิบาย (กรอกเพิ่มเองได้) |
| `Color_Shades` | รหัสเฉดสี (`A`,`Y`,`Z`,`B`) + คำอธิบาย (**ยังว่าง รอกรอกเพิ่มภายหลังตามที่แจ้งไว้**) |
| `BOM_Orders` | หัวรายการ BOM ที่บันทึกจากเว็บแต่ละครั้ง (1 แถว = 1 คำสั่งผลิต) |
| `BOM_Order_Lines` | รายการวัตถุดิบของแต่ละคำสั่งผลิต (อ้างอิงกลับด้วย `ORDER_ID`) |

ข้อมูลใน `BOM_Master`/`Materials_Catalog`/`FG_Base_Items`/`Packaging_Codes`/`Color_Shades` ถูกนำเข้าครั้งเดียวตอน `initializeSheet()` — ถ้าชีทมีข้อมูลอยู่แล้วจะไม่ถูกเขียนทับซ้ำ (ปลอดภัยต่อการรันซ้ำ) แต่ `BOM_Orders`/`BOM_Order_Lines` จะถูกเพิ่มแถวใหม่ทุกครั้งที่มีการบันทึกจากเว็บ

## หมายเหตุด้านข้อมูล

- ข้อมูล `BOM_Master` และ `Materials_Catalog` แปลงมาจากชีท `DATA` ในไฟล์ `Test_Material_MP_MRP_4.1...xlsm` ที่ให้มา (884 รหัสสินค้า, 1,799 แถวสูตรวัตถุดิบ, วัตถุดิบไม่ซ้ำ 1,016 รายการ)
- รูปแบบรหัส ITEM (`ฐาน(Packaging)-เฉดสี`) วิเคราะห์มาจากไฟล์ `...26070126030_FIRST...REV_0.xlsx` พบรหัส Packaging 4 แบบ (`P`,`B`,`X`,`C`) และรหัสเฉดสี 4 แบบ (`A`,`Y`,`Z`,`B`) — **ความหมายของแต่ละรหัสยังไม่ทราบแน่ชัดจากไฟล์ต้นฉบับ** จึงเว้นช่องคำอธิบายไว้ให้กรอกเพิ่มเติมเองในชีท `Packaging_Codes` / `Color_Shades` หรือผ่านเว็บแอปได้เลย

## การแก้ไข/อัปเดตข้อมูลตั้งต้นในอนาคต

ถ้าต้องการนำเข้าข้อมูลจากไฟล์ Excel ชุดใหม่ ให้ปรับ `scripts/extract.py` และ `scripts/gen_seed.py` แล้วรันใหม่เพื่อสร้าง `apps-script/SeedData.gs` ฉบับใหม่ จากนั้นวางทับใน Apps Script editor แล้ว Deploy เวอร์ชันใหม่ (ข้อมูลเดิมในชีทจะไม่ถูกลบ เพราะ `initializeSheet()` เขียนเฉพาะตอนชีทว่างเท่านั้น)
